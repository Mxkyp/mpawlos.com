## Associated terms
1. *White hat hacking / ethical hacking* - hacking done purposely for the sake of analyzing vulnerabilities in a system.
2. Unauthorized / authorized layer - the separation of a system, to the part available to **authorized users** and the part available to **unauthorized users**.
3. Authentication - The verification of use's identity. We can differentiate between many different types of Authentication for example: **Credential based(password and email), Two Factor auth: (card and pin), Hardware based:(car key).**
4. Authorization - Allowing/Disallowing the usage of a certain resource based on the **user's identity**. 

## Basic security checklist
- [ ] One security breach is enough to compromise the whole system?
- [ ] The sensitive data is encrypted and masked?
- [ ] Is SSL security enabled?
