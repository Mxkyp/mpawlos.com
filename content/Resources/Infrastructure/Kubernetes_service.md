# Simply
Services provide [Kubernetes](../../Areas/Tech-Stack/Kubernetes.md) **cluster-system-outside** communication capabilities. 
Only their metadata name is used as a DNS domain.

## Types

1. ClusterIP
Creates a cluster wide ip address.

2. LoadBalancer
Connects with external lodeBalancer and manages the load

3. NodePort

4. ExternalName

5. headless
