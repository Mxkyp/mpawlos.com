## Java virtual machine
A program which executes Java bytecode(.class files) created by javac(from .java files)

### compilation process
1. java files get compiled by **javac** into .class files.
2. .class files get loaded into the **JVM**.
3. The **JVM** starts execution from main() or the method selected as main.
