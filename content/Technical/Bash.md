# (Bourne again shell)
---

Bash is a successor of the shell creates by (To be filled) Bourne.
It's used by most Linux distribution and certifications exams.


## Bash configuration files
There are 4 main bash configuration files.

The ones important from the user standpoint are:
1. ~/.bashrc (stuff to execute each time a shell is opened)
2. ~/.bash_logout (stuff that executes each time a shell is closed;)

## Bash Commands

|Command       | Description |
| ----------- | ----------- |
| id      | give information about current user his idenity and the groups he belongs to   |
| who   | gives information about current session        |
| type (command)| gives information about the location of a command(that is int PATH)        |
| locate (command) | gives information about the location of a command(NOT in PATH)        |
| history | gives command history(duh)        |
