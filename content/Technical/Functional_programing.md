## Simply 
A [***declarative programming***](./Declarative_programming.md) **paradigm**.

## History 
The beginning of functional Programming goes back to 1930's to the formalization of **lambda calculus**.At that time Alonzo Church experimented with [Higher order functions](#hef).

## Higher order functions (#hef)
**Higher order functions** can perform operations on functions, take them as arguments and return them.

## First order function
Is a function which can be defined as a variable and passed as an argument.

### Rules
1. Immutable data.
2. Functions have no side effects. Function doesn't change an app state, define a global variable. They only return a value.
